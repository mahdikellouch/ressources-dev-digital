1. Introduction à Visual Studio Code

Visual Studio Code (VS Code) est un éditeur de code source gratuit, open source et multiplateforme développé par Microsoft. Lancé en 2015, il est aujourd'hui l'outil de prédilection de millions de développeurs.

Contrairement à un IDE complet comme Visual Studio, VS Code est un éditeur léger qui peut être transformé en véritable environnement de développement grâce à ses extensions. Il supporte nativement JavaScript, TypeScript et Node.js, et via des extensions : Python, Java, C++, PHP, HTML, CSS, etc.

Caractéristiques principales

  • ✅ Gratuit et open source
  • ✅ Multiplateforme (Windows, macOS, Linux)
  • ✅ Léger et rapide
  • ✅ Éditeur intelligent (IntelliSense)
  • ✅ Débogage intégré
  • ✅ Écosystème de 40 000+ extensions
  • ✅ Intégration Git native
💡 À retenir

VS Code n'est pas un simple bloc-notes. C'est un environnement de développement complet qui, grâce à ses extensions, rivalise avec les IDE les plus puissants.

3. Les Fonctionnalités Clés de VS Code

3.1 Édition intelligente (IntelliSense)

VS Code comprend votre code et vous assiste en temps réel.

FonctionnalitéDescription
Coloration syntaxiqueDistingue visuellement les mots-clés, chaînes, commentaires par des couleurs.
Auto-complétionPropose des suggestions pendant la saisie (fonctions, variables, propriétés).
Détection d'erreursSouligne les erreurs en rouge (syntaxe) ou bleu (sémantique).
Pliage de codeReplie/déplie les blocs de code pour faciliter la navigation.
Multi-curseursÉdite plusieurs lignes simultanément (Alt + Clic).
Détection du langageIdentifie le langage selon l'extension du fichier (.html, .css, .py, .js).
💡 Détection automatique du langage

VS Code reconnaît automatiquement le langage grâce à l'extension du fichier : .html → HTML, .css → CSS, .js → JavaScript, .py → Python, .java → Java.

3.2 Débogage (Debugger)

VS Code intègre un débogueur qui permet d'exécuter le code pas à pas et d'inspecter les variables.

  • Points d'arrêt : Cliquez sur la marge gauche pour ajouter un point rouge.
  • Point conditionnel : Clic droit → Ajouter un point conditionnel (ex: i > 10).
  • Panneau VARIABLES : Affiche les variables locales et globales.
  • Panneau WATCH : Surveille des expressions personnalisées.
  • CALL STACK : Affiche la pile d'appels des fonctions.
  • DEBUG CONSOLE : Exécute du code pendant la pause.

3.3 Terminal intégré

  • Raccourci : Ctrl + ` (Windows/Linux) ou Cmd + ` (macOS).
  • Supporte : PowerShell, Invite de commandes, Bash, Zsh.
  • Multi-terminaux : Plusieurs instances simultanées.

3.4 Intégration Git

VS Code intègre nativement Git dans la barre latérale "Contrôle de code source" :

  • Statuts : M = Modifié, U = Non suivi, A = Indexé.
  • Actions : Valider, Tirer, Pousser, Créer une branche.
  • Diff visuel directement dans l'éditeur.

3.5 Palette de commandes

Véritable couteau suisse de VS Code :

  • Raccourci : Ctrl + Shift + P.
  • Recherche floue : taper odks trouve "Open Default Keyboard Shortcuts".

5. Installation et Configuration

5.1 Étapes d'installation

  1. Rendez-vous sur https://code.visualstudio.com
  2. Le site détecte automatiquement votre OS.
  3. Cliquez sur le bouton de téléchargement.
  4. Lancez l'installateur et acceptez la licence.
  5. Choisissez l'installation Utilisateur (recommandée).
  6. Terminez et lancez VS Code.

5.2 Configuration recommandée

ParamètreValeurDescription
files.autoSaveonFocusChangeSauvegarde auto lors du changement de fenêtre.
editor.formatOnSavetrueFormate le code à chaque sauvegarde.
editor.fontFamilyConsolas, monospacePolice adaptée au code.
editor.fontSize14Taille du texte adaptée.
editor.tabSize2Indentation par défaut (Web).

6. Atelier Pratique : Premier Projet Web

Objectif : Créer un mini-site web (HTML + CSS + JS) avec VS Code.

Étape 1 : Créer le dossier du projet

Ouvrez VS Code → Fichier → Ouvrir un dossier → Créez mon-premier-site.

Étape 2 : Créer le fichier index.html

Clic droit dans l'explorateur → Nouveau fichier → index.html

Astuce : tapez ! puis Tab pour générer la structure HTML5 automatique.

<!DOCTYPE html>
<html lang="fr">
<head>
  <meta charset="UTF-8">
  <title>Mon Premier Site</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <h1>Bienvenue sur mon site !</h1>
  <p>Créé avec Visual Studio Code</p>
  <script src="script.js"></script>
</body>
</html>

Étape 3 : Créer le fichier style.css

body {
  font-family: Arial, sans-serif;
  background: #f0f4f8;
  text-align: center;
  padding: 50px;
}
h1 { color: #1F3A5F; }
p { color: #2E8B57; }

Étape 4 : Créer le fichier script.js

document.querySelector("h1").addEventListener("click", () => {
  alert("Vous avez cliqué sur le titre !");
});

Étape 5 : Lancer avec Live Server

  • Clic droit sur index.html → Open with Live Server.
  • Le navigateur s'ouvre sur http://127.0.0.1:5500.
  • Chaque modification est rechargée automatiquement.
✅ Résultat attendu

Une page web interactive avec un titre cliquable, stylisée en CSS, le tout créé avec VS Code et Live Server.
