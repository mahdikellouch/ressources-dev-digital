IMAGES DU PROJET GREEN TECH SOLUTIONS
======================================

Ce dossier doit contenir les images utilisées dans le site.

Images à prévoir :
------------------

1. logo.png
   - Logo de GreenTech Solutions (ou texte simple stylisé en CSS)
   - Format : PNG transparent
   - Taille conseillée : 200x60px

2. hero.jpg
   - Image d'illustration pour la section Hero de la page d'accueil
   - Format : JPG
   - Taille conseillée : 1920x1080px
   - Thème : nature, technologie verte, énergie renouvelable

3. service-1.jpg, service-2.jpg, service-3.jpg
   - Images pour les 3 cartes de services (page d'accueil)
   - Format : JPG
   - Taille conseillée : 600x400px

4. apropos.jpg
   - Image pour la section "À propos" (page d'accueil)
   - Format : JPG
   - Taille conseillée : 800x600px

5. map.jpg (optionnel)
   - Image de carte statique pour la page contact
   - Format : JPG
   - Taille conseillée : 1200x400px


Où trouver des images gratuites ?
----------------------------------

- Unsplash : https://unsplash.com
- Pixabay : https://pixabay.com
- Pexels : https://pexels.com
- Freepik (avec attribution) : https://freepik.com


Que faire si vous n'avez pas d'images ?
----------------------------------------

Pour le développement, vous pouvez utiliser :
- Des images placeholder : https://placehold.co/600x400
- Des blocs CSS colorés à la place des images
- Des emojis à la place des icônes (🌱💻📊☁️🔒🎓)

Exemple de placeholder en HTML :
<img src="https://placehold.co/600x400/2e8b57/ffffff?text=Service+1" alt="Service 1">


N'oubliez pas :
---------------

- Toutes les images doivent avoir un attribut alt (accessibilité)
- Optimisez les images (compression) pour un site rapide
- Utilisez des noms de fichiers clairs et en minuscules
