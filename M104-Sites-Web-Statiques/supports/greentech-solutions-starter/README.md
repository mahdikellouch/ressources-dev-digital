

# 🚀 Projet GreenTech Solutions · Guide de démarrage

Bienvenue dans votre projet final du Chapitre 4 !
Ce dossier contient la **structure de départ** à compléter.

---

## 📋 Contenu du projet

greentech-solutions-starter/
├── index.html                    ← Page d'accueil (structure HTML complète, sans CSS)
├── services.html                 ← Page services (structure HTML complète, sans CSS)
├── contact.html                  ← Page contact (structure HTML complète, sans CSS)
├── css/
│   └── style.css                 ← Feuille de style VIDE avec commentaires-guides
├── images/
│   └── README.txt                ← Instructions pour les images
└── README.md                     ← Guide de démarrage pour les stagiaires


---

## 🎯 Votre mission

1. **Lier la feuille de style** dans les 3 fichiers HTML
   (décommentez la ligne `<link rel="stylesheet" href="css/style.css">`)

2. **Compléter `css/style.css`** en suivant les commentaires-guides
   (chaque section du CSS correspond à une partie du HTML)

3. **Ajouter vos images** dans le dossier `images/`
   (voir `images/README.txt` pour les instructions)

4. **Tester le rendu** dans un navigateur (Live Server recommandé)

5. **Valider votre code** sur :
   - HTML : https://validator.w3.org
   - CSS : https://jigsaw.w3.org/css-validator

## ✅ Checklist avant remise

- [ ] Les 3 fichiers HTML sont valides W3C
- [ ] Le fichier CSS est valide W3C
- [ ] Le header est sticky ou fixed
- [ ] Au moins 2 sections utilisent flexbox
- [ ] Une media query est présente pour le mobile
- [ ] Au moins un dégradé est utilisé
- [ ] Le reset CSS avec `box-sizing: border-box` est présent
- [ ] Les 3 notations de couleur (HEX, RGB, HSL) sont utilisées
- [ ] Les 3 unités (px, rem, %) sont utilisées
- [ ] Toutes les images ont un attribut `alt`
- [ ] Les contrastes sont suffisants (test WebAIM)
- [ ] Le code est indenté et commenté
