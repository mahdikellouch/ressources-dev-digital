1. Structure d'une page HTML5

1.1 Le squelette HTML5

Toute page HTML5 respecte une structure minimale appelée squelette. Elle est composée de balises obligatoires que le navigateur interprète pour afficher correctement le contenu.

<!-- Déclaration du type de document --> <!DOCTYPE html> <html lang="fr"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>Ma première page</title> </head> <body> <!-- Contenu visible de la page --> <h1>Bienvenue</h1> </body> </html>

Rôle de chaque balise

BaliseRôleObligatoire ?
<!DOCTYPE html>Indique au navigateur qu'il s'agit de HTML5✅ Oui
<html>Racine du document✅ Oui
<head>Métadonnées (titre, encodage, styles)✅ Oui
<body>Contenu visible de la page✅ Oui
<title>Titre affiché dans l'onglet✅ Oui
<meta charset="UTF-8">Encodage des caractères✅ Recommandé
⚠️ Attention : la balise <title> ne doit jamais être vide. C'est elle qui apparaît dans l'onglet du navigateur et dans les résultats de recherche Google.
Consigne : Observez le code ci-dessous. Identifiez les 4 balises obligatoires du squelette HTML5 et indiquez leur rôle.

<!DOCTYPE html>
<html lang="fr">
<head><title>Test</title></head>
<body><h1>Bonjour</h1></body>
</html>
⏳ 30 s
💡 Solution :
1. <!DOCTYPE html> → déclare HTML5
2. <html> → racine du document
3. <head> → métadonnées (ici le titre)
4. <body> → contenu visible (ici le h1)

2. Balises de base

2.1 Les titres : <h1> à <h6>

HTML propose 6 niveaux de titres. Le <h1> est le plus important, le <h6> le moins important.

<h1>Titre principal</h1> <h2>Sous-titre</h2> <h3>Sous-sous-titre</h3> <h4>Niveau 4</h4> <h5>Niveau 5</h5> <h6>Niveau 6</h6>
📌 Règle W3C : une page ne doit contenir qu'un seul <h1>. Les niveaux doivent être hiérarchisés (ne pas passer de h1 à h4).

2.2 Les paragraphes : <p>

Le paragraphe <p> sert à regrouper du texte. Il crée automatiquement un espace avant et après le bloc.

<p>Ceci est un paragraphe de texte.</p> <p>Ceci est un deuxième paragraphe.</p>

2.3 Les listes : <ul>, <ol>, <li>

Il existe deux types de listes :

  • <ul> : liste non ordonnée (puces)
  • <ol> : liste ordonnée (numérotée)
  • <li> : élément de liste (utilisé dans les deux cas)
<!-- Liste à puces --> <ul> <li>HTML</li> <li>CSS</li> <li>JavaScript</li> </ul> <!-- Liste numérotée --> <ol> <li>Première étape</li> <li>Deuxième étape</li> </ol>

2.4 Les liens : <a>

Le lien hypertexte <a> permet de naviguer vers une autre page, un site externe, un fichier, ou une ancre interne.

<!-- Lien vers un site externe --> <a href="https://www.ofppt.ma">Site de l'OFPPT</a> <!-- Lien vers une page interne --> <a href="contact.html">Nous contacter</a> <!-- Lien qui ouvre un nouvel onglet --> <a href="https://www.google.com" target="_blank">Google</a>
💡 Attribut target="_blank" : ouvre le lien dans un nouvel onglet. À utiliser avec parcimonie.

2.5 Les images : <img>

La balise <img> est auto-fermante (pas de balise de fermeture). Elle nécessite au minimum deux attributs : src et alt.

<img src="images/photo.jpg" alt="Photo de profil" width="200" height="200">
⚠️ Important : l'attribut alt est obligatoire (norme W3C). Il décrit l'image pour les lecteurs d'écran et s'affiche si l'image ne charge pas.

2.6 Les tableaux : <table>, <tr>, <th>, <td>

Un tableau HTML est composé de lignes et de cellules :

  • <table> : conteneur du tableau
  • <tr> : ligne (table row)
  • <th> : cellule d'en-tête (table header)
  • <td> : cellule de données (table data)
<table> <tr> <th>Nom</th> <th>Âge</th> </tr> <tr> <td>Alice</td> <td>25</td> </tr> </table>
Consigne : Écrivez le code HTML pour créer une liste non ordonnée contenant 4 fruits, puis une liste ordonnée contenant 3 étapes pour préparer un thé.
⏳ 60 s
💡 Solution :
<ul>
  <li>Pomme</li>
  <li>Banane</li>
  <li>Orange</li>
  <li>Fraise</li>
</ul>

<ol>
  <li>Faire bouillir l'eau</li>
  <li>Ajouter le thé</li>
  <li>Laisser infuser 3 minutes</li>
</ol>

3. Attributs essentiels

Les attributs enrichissent les balises en leur ajoutant des informations. Ils se placent toujours dans la balise ouvrante et sont suivis d'une valeur entre guillemets.

AttributUtilisationExemple
hrefURL de destination (liens)<a href="page.html">
srcChemin de la ressource (images, scripts)<img src="photo.jpg">
altTexte alternatif (images)<img alt="Photo">
titleInfo-bulle au survol<p title="Astuce">
idIdentifiant unique dans la page<div id="header">
classGroupe d'éléments (réutilisable)<p class="intro">
📌 Différence entre id et class :
• id est unique dans la page (une seule balise peut le porter).
• class peut être réutilisée sur plusieurs balises.
Consigne : Pour chaque situation, indiquez s'il faut utiliser id ou class :
1. Le titre principal d'une page unique.
2. Tous les paragraphes d'introduction.
3. Le pied de page commun à toutes les pages.
4. Une section "actualités" présente sur chaque page.
⏳ 45 s
💡 Solution :
1. id (un seul titre principal)
2. class (plusieurs paragraphes partagent le même style)
3. id ou class selon qu'il est unique ou répété — en général id="footer" une seule fois par page
4. class (réutilisable sur plusieurs pages)

4. Normes du W3C

Le W3C (World Wide Web Consortium) définit les standards du web. Respecter ces normes garantit que votre code fonctionne sur tous les navigateurs et reste accessible.

4.1 Les règles fondamentales

  • Balises en minuscules : écrivez <p> et non <P>.
  • Fermeture des balises : toute balise ouvrante doit être fermée (<p>...</p>).
  • Imbrication correcte : les balises doivent être fermées dans l'ordre inverse de leur ouverture.
  • Attributs entre guillemets : href="page.html" et non href=page.html.
  • Un seul <h1> par page : hiérarchisez les titres.
  • Attribut alt obligatoire sur toutes les images.

4.2 Exemples de bonnes et mauvaises pratiques

❌ Mauvaise pratique

<P>Texte <img src=photo.jpg> <b><i>Gras et italique<b></i>

✅ Bonne pratique

<p>Texte</p> <img src="photo.jpg" alt="Description"> <b><i>Gras et italique</i></b>
✅ Vérification : utilisez le validateur W3C pour tester votre code HTML gratuitement.
Consigne : Identifiez toutes les erreurs dans ce code HTML :

<HTML>
<head><title>Test</title>
<body>
<H1>Bonjour</h1>
<p>Texte</P>
<img src=photo.jpg>
<b><i>Test</b></i>
</body>
</HTML>
⏳ 90 s
💡 Erreurs détectées :
1. <HTML> et </HTML> en majuscules → doivent être en minuscules.
2. <head> non fermée.
3. <H1> en majuscules, </h1> en minuscules → incohérence.
4. </P> en majuscules.
5. src=photo.jpg sans guillemets et sans alt.
6. <b><i>...</b></i> → imbrication incorrecte (le <i> doit être fermé avant </b>).

5. Chemins d'accès

Un chemin d'accès indique où se trouve une ressource (image, fichier, page). Il existe deux types : absolu et relatif.

5.1 Chemin absolu

Il commence par un protocole (http://, https://) ou un slash initial /. Il pointe toujours vers la même ressource, indépendamment de l'emplacement du fichier HTML.

<img src="https://example.com/images/logo.png"> <a href="https://www.ofppt.ma">OFPPT</a>

5.2 Chemin relatif

Il est relatif à l'emplacement du fichier HTML qui le contient. C'est la méthode recommandée pour un site local.

SyntaxeSignification
image.jpgMême dossier
images/image.jpgSous-dossier images/
../image.jpgDossier parent
../../image.jpgDeux niveaux au-dessus
/image.jpgRacine du site

5.3 Arborescence recommandée

📁 mon-site/ ├── index.html ├── contact.html ├── 📁 images/ │ ├── logo.png │ └── photo.jpg ├── 📁 css/ │ └── style.css └── 📁 js/ └── script.js
Consigne : Pour chaque situation, indiquez le chemin relatif correct :
1. Depuis index.html (racine), accéder à images/logo.png.
2. Depuis pages/contact.html, accéder à images/logo.png.
3. Depuis pages/blog/article.html, accéder à css/style.css.
⏳ 60 s
💡 Solution :
1. images/logo.png
2. ../images/logo.png (remonter d'un niveau)
3. ../../css/style.css (remonter de deux niveaux)

6. Balises sémantiques HTML5

Les balises sémantiques décrivent le rôle du contenu qu'elles contiennent. Elles améliorent l'accessibilité, le référencement (SEO) et la lisibilité du code.

BaliseRôle
<header>En-tête de page ou de section
<nav>Menu de navigation
<main>Contenu principal (unique par page)
<section>Section thématique
<article>Contenu autonome (article, actualité)
<aside>Contenu complémentaire (encadré)
<footer>Pied de page

6.1 Exemple de structure sémantique complète

<body> <header> <h1>Mon site</h1> <nav> <a href="#accueil">Accueil</a> <a href="#contact">Contact</a> </nav> </header> <main> <section id="accueil"> <h2>Bienvenue</h2> <p>Présentation du site.</p> </section> <article> <h2>Dernière actualité</h2> <p>Contenu de l'article.</p> </article> </main> <footer> <p>© 2025 Mon site</p> </footer> </body>
💡 Pourquoi utiliser les balises sémantiques ?
• Accessibilité : les lecteurs d'écran comprennent mieux la structure.
• SEO : Google identifie les zones importantes du contenu.
Lisibilité : le code est plus clair pour les développeurs.
Consigne : Associez chaque contenu à la balise sémantique la plus appropriée :
1. Le logo et le titre du site.
2. Les liens vers les autres pages.
3. Un article de blog.
4. Les mentions de copyright en bas de page.
5. Les coordonnées de contact dans une barre latérale.
⏳ 45 s
💡 Solution :
1. <header>
2. <nav>
3. <article>
4. <footer>
5. <aside>

7. Exercices pratiques

Exercice 1 · Ma première page

Créez un fichier index.html qui contient :

  • Un titre principal <h1> avec votre nom.
  • Un paragraphe de présentation.
  • Une liste non ordonnée de vos 3 centres d'intérêt.
  • Un lien vers le site de l'OFPPT.

Exercice 2 · Page de recettes

Créez une page recette.html contenant :

  • Un titre <h1> avec le nom de la recette.
  • Une image illustrative (avec alt).
  • Une liste ordonnée des étapes.
  • Une liste non ordonnée des ingrédients.

Exercice 3 · Page de contact

Créez une page contact.html structurée avec les balises sémantiques :

  • <header> avec un titre.
  • <nav> avec 3 liens.
  • <main> avec un paragraphe de description.
  • <footer> avec vos coordonnées.

Exercice 4 · Tableau comparatif

Créez un tableau HTML comparant 3 langages (HTML, CSS, JavaScript) avec les colonnes : nom, rôle, difficulté.

Exercice 5 · Corriger une page

Voici un code HTML contenant 5 erreurs W3C. Corrigez-les :

10. Projet final

📌 Créer un CV en ligne

Contexte : Vous devez créer une page web présentant votre CV. Cette page servira de portfolio pour votre recherche de stage.

📋 Contenu obligatoire

  • En-tête (<header>) : nom, prénom, titre professionnel, photo.
  • Navigation (<nav>) : liens vers les sections (ancre interne).
  • Section "À propos" : paragraphe de présentation.
  • Section "Formation" : liste ordonnée des diplômes.
  • Section "Compétences" : liste non ordonnée (avec niveaux).
  • Section "Expériences" : tableau avec colonnes (période, entreprise, poste).
  • Section "Contact" : liens (email, LinkedIn, GitHub).
  • Pied de page (<footer>) : mentions légales.
📦 Livrables attendus :
  • Fichier cv.html valide W3C.
  • Dossier images/ avec les visuels.
  • Respect des normes sémantiques.
  • Un seul <h1> par page.
  • Attributs alt sur toutes les images.
