1. Définitions Fondamentales

1.1 Le World Wide Web (WWW)

Le WWW n'est pas Internet. Internet est l'infrastructure réseau (câbles, serveurs, routeurs), tandis que le WWW est un service qui utilise cette infrastructure pour partager des documents hypertextes.

  • Définition : Système d'information distribué basé sur l'hypertexte, accessible via Internet.
  • Composants clés : HTML (structure), HTTP (protocole), URL (adresse).
🎬 Animation : Internet (autoroute) vs WWW (camions)

2. Le Modèle Client-Serveur

C'est l'architecture fondamentale du Web. Le client (navigateur) demande une ressource, le serveur la fournit.

  • Le Client : Généralement le navigateur web. Il envoie des requêtes.
  • Le Serveur : Ordinateur puissant hébergeant les fichiers du site. Il renvoie des réponses.
  • Analogie : Le client est un client au restaurant qui commande un plat (requête). Le serveur est le cuisinier qui prépare et apporte le plat (réponse).
🎬 Animation : Cycle Requête / Réponse HTTP (UML)

3. URL & Hyperliens

3.1 Les URL (Uniform Resource Locator)

L'URL est l'adresse unique d'une ressource sur le Web.

  • Structure : protocole://sous-domaine.domaine.extension/chemin/ressource
  • Exemple : https://www.ofppt.ma/formation/ismo
  • https : Protocole sécurisé.
  • www : Sous-domaine.
  • ofppt.ma : Nom de domaine.
  • /formation/ismo : Chemin d'accès au fichier.

3.2 Les Hyperliens (Liens)

Élément cliquable permettant de naviguer d'une page à une autre. C'est ce qui fait du Web une "toile" (Web).

<a href="url">Texte du lien</a>

5. Le W3C (World Wide Web Consortium)

  • Rôle : Organisme international qui développe des standards ouverts pour le Web.
  • Objectifs :
    • Interopérabilité : S'assurer que tous les navigateurs comprennent le même code.
    • Accessibilité : Rendre le Web accessible aux personnes handicapées (normes WCAG).
    • Évolution : Développer les technologies futures (HTML, CSS, XML).

6. Les Navigateurs Web

6.1 Rôle

Le navigateur est le logiciel client qui :

  1. Interprète le code (HTML, CSS, JavaScript).
  2. Gère les requêtes HTTP vers les serveurs.
  3. Affiche le rendu visuel (moteur de rendu).

6.2 Fonctionnement (Cycle Requête/Réponse)

  1. Saisie URL : L'utilisateur tape une adresse.
  2. Résolution DNS : Le navigateur trouve l'adresse IP du serveur.
  3. Requête HTTP : Envoi d'une demande (ex: GET /index.html).
  4. Réponse Serveur : Le serveur renvoie le code HTML avec un code statut (ex: 200 OK).
  5. Rendu : Le navigateur analyse le HTML, charge le CSS, exécute le JS et peint l'écran.
🎬 Démonstration en classe

Outil : Utilisez les DevTools (F12) dans Chrome → onglet "Network" (Réseau).

Action : Rechargez une page et montrez les requêtes qui défilent en temps réel (codes 200, 304, etc.).
