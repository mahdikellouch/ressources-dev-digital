2. Syntaxe CSS et modes d'intégration

2.1 La syntaxe d'une règle CSS

Une règle CSS se compose de trois éléments :

/* Structure d'une règle CSS */ selecteur { propriete: valeur; autre-propriete: autre-valeur; }
Élément Rôle Exemple
Sélecteur Cible les éléments HTML à styliser p, .intro, #header
Propriété Aspect à modifier color, font-size, margin
Valeur Valeur à appliquer red, 16px, 10px

2.2 Exemple de règle CSS complète

/* Cette règle cible tous les paragraphes <p> */ p { color: #333333; /* Couleur du texte : gris foncé */ font-size: 16px; /* Taille de la police */ line-height: 1.6; /* Hauteur de ligne */ margin-bottom: 15px; /* Espace sous le paragraphe */ }
📌 Règles d'écriture :
• Chaque déclaration (propriété: valeur) se termine par un point-virgule ;
• Le bloc de déclarations est entouré d'accolades { }
• Les commentaires sont entre /* ... */

2.3 Les trois modes d'intégration du CSS

Il existe trois façons d'intégrer du CSS dans une page HTML :

🔹 Mode 1 · CSS en ligne (inline)

Le style est directement écrit dans la balise HTML via l'attribut style.

<p style="color: red; font-size: 18px;">Texte rouge en 18px</p>
⚠️ À éviter : le CSS inline est difficile à maintenir. À réserver aux tests rapides ou aux cas très spécifiques (emails HTML).

🔹 Mode 2 · CSS interne (embedded)

Le style est écrit dans une balise <style> dans la partie <head> du document.

<head> <style> p { color: blue; font-size: 16px; } </style> </head>
💡 Usage : le CSS interne est utile pour une page unique ou pour tester rapidement.

🔹 Mode 3 · CSS externe (recommandé)

Le style est écrit dans un fichier séparé avec l'extension .css, puis lié au HTML via la balise <link>.

<!-- Dans le <head> du fichier HTML --> <link rel="stylesheet" href="style.css">
/* Dans le fichier style.css */ p { color: green; font-size: 16px; }
✅ Bonne pratique : c'est la méthode recommandée pour tout site professionnel. Un seul fichier CSS peut être partagé par toutes les pages du site.

2.4 Comparaison des trois modes

Critère Inline Interne Externe
Séparation HTML/CSS ❌ Non ⚠️ Partielle ✅ Oui
Réutilisable sur plusieurs pages ❌ Non ❌ Non ✅ Oui
Maintenance ❌ Difficile ⚠️ Moyenne ✅ Facile
Mise en cache navigateur ❌ Non ❌ Non ✅ Oui
Usage recommandé Cas ponctuels Page unique Site professionnel

2.5 Exemple complet : les trois modes côte à côte

Exemple 1 — CSS inline

<!DOCTYPE html> <html> <body> <h1 style="color: #1d5e36;">Titre vert</h1> </body> </html>

Exemple 2 — CSS interne

<!DOCTYPE html> <html> <head> <style> h1 { color: #1d5e36; } </style> </head> <body> <h1>Titre vert</h1> </body> </html>

Exemple 3 — CSS externe

<!-- Fichier index.html --> <!DOCTYPE html> <html> <head> <link rel="stylesheet" href="style.css"> </head> <body> <h1>Titre vert</h1> </body> </html> /* Fichier style.css */ h1 { color: #1d5e36; }

3. Les sélecteurs de base

3.1 Qu'est-ce qu'un sélecteur CSS ?

Un sélecteur CSS est un motif qui permet de cibler un ou plusieurs éléments HTML dans le but de leur appliquer un style. C'est le point de départ de toute règle CSS.

💡 Analogie : un sélecteur CSS fonctionne comme un filtre. Imaginez une base de données de milliers d'éléments HTML : le sélecteur dit « je veux uniquement ceux qui correspondent à ce critère ».

3.2 Les 4 sélecteurs fondamentaux

Sélecteur Syntaxe Cible Exemple
Universel * Tous les éléments * { margin: 0; }
Balise element Toutes les balises du type p { color: gray; }
Classe .nom-classe Tous les éléments portant la classe .intro { font-size: 18px; }
Identifiant #nom-id L'élément unique portant l'id #header { background: green; }

🔹 Le sélecteur universel *

Cible tous les éléments de la page. Souvent utilisé pour un reset global.

/* Retire les marges et paddings par défaut de tous les éléments */ * { margin: 0; padding: 0; box-sizing: border-box; }
⚠️ Attention : le sélecteur universel peut être coûteux en performance sur de très grosses pages. À utiliser avec discernement.

🔹 Le sélecteur de balise

Cible toutes les balises d'un type donné dans le document.

/* Tous les paragraphes <p> auront ces styles */ p { color: #333; line-height: 1.6; } /* Tous les liens <a> seront verts et sans soulignement */ a { color: #1d5e36; text-decoration: none; }

🔹 Le sélecteur de classe

En HTML, une classe se déclare avec l'attribut class. En CSS, on la cible avec un point ..

<!-- HTML : deux paragraphes, un seul avec la classe "intro" --> <p class="intro">Ce paragraphe est stylisé.</p> <p>Ce paragraphe reste normal.</p> /* CSS : on cible uniquement la classe "intro" */ .intro { font-size: 18px; font-weight: bold; color: #2e8b57; }
✅ Bonne pratique : les classes sont la méthode la plus utilisée en CSS moderne. Elles sont réutilisables sur plusieurs éléments et indépendantes de la structure HTML.

🔹 Le sélecteur d'identifiant

En HTML, un identifiant se déclare avec l'attribut id. En CSS, on le cible avec un dièse #.

<!-- HTML : un seul élément avec l'id "header" --> <header id="header"> <h1>Mon site</h1> </header> /* CSS : on cible l'id unique "header" */ #header { background-color: #1d5e36; color: white; padding: 20px; }
⚠️ Règle W3C : un identifiant id doit être unique dans toute la page. Deux éléments ne peuvent pas porter le même id.

3.3 Classe ou identifiant : que choisir ?

Critère Classe . Identifiant #
Réutilisable ✅ Sur plusieurs éléments ❌ Un seul par page
Syntaxe HTML class="nom" id="nom"
Syntaxe CSS .nom { } #nom { }
Spécificité Faible (10 points) Forte (100 points)
Usage recommandé Mise en forme générale Éléments uniques (header, footer)
📌 Règle simple : utilisez toujours des classes, sauf pour les éléments strictement uniques comme un header principal, un pied de page, ou une section spéciale.

3.4 Le sélecteur groupé

Il permet d'appliquer le même style à plusieurs sélecteurs en les séparant par une virgule.

/* Sans groupement */ h1 { font-family: Arial; } h2 { font-family: Arial; } h3 { font-family: Arial; } /* Avec groupement (plus concis) */ h1, h2, h3 { font-family: Arial; }

3.5 Le sélecteur descendant

Il cible un élément à l'intérieur d'un autre, en séparant les sélecteurs par un espace.

<!-- HTML --> <nav> <a href="#">Lien dans nav</a> </nav> <p> <a href="#">Lien dans p</a> </p> /* CSS : uniquement les <a> à l'intérieur de <nav> */ nav a { color: white; text-decoration: none; }
✅ Avantage : le sélecteur descendant permet de limiter la portée d'un style à un contexte précis, évitant ainsi les effets de bord.

3.6 Récapitulatif avec exemple complet

<!-- HTML --> <body> <header id="header"> <h1 class="titre-principal">Mon site</h1> <p class="intro">Bienvenue sur mon site.</p> </header> <p>Un paragraphe normal.</p> </body> /* CSS correspondant */ * { margin: 0; padding: 0; } p { color: #333; line-height: 1.6; } .intro { font-size: 18px; font-weight: bold; } #header { background: #1d5e36; color: white; } .titre-principal { font-size: 32px; }

2. Toutes les citations mises en valeur
3. Le pied de page commun (footer)
4. Tous les boutons "action" du site
5. La barre de navigation principale
6. Tous les paragraphes d'introduction
7. Une section de contact unique
8. Toutes les images avec effet "vignette"

💡 Solution :
1. Identifiant — un seul titre principal par page
2. Classe — plusieurs citations peuvent partager le même style
3. Identifiant — un seul footer par page
4. Classe — plusieurs boutons partagent le même style
5. Identifiant — une seule barre de navigation par page
6. Classe — plusieurs paragraphes peuvent être des introductions
7. Identifiant — une seule section de contact

Consigne : Écrivez le sélecteur CSS correct pour chaque situation décrite dans l'énoncé ci-dessous.

6. * { }

4. Les sélecteurs avancés

4.1 Le sélecteur d'enfant direct >

Le sélecteur > cible un élément enfant direct d'un autre élément, mais pas les descendants plus profonds.

<!-- HTML --> <ul class="menu"> <li>Accueil <ul> <li>Sous-menu</li> </ul> </li> </ul> /* Cible uniquement les <li> enfants directs de .menu */ .menu > li { color: red; } /* "Accueil" sera rouge, "Sous-menu" ne le sera pas */

4.2 Le sélecteur d'adjacence immédiate +

Cible l'élément qui suit immédiatement un autre élément au même niveau.

<!-- HTML --> <h2>Titre</h2> <p>Paragraphe suivant le titre</p> <p>Deuxième paragraphe</p> /* Cible uniquement le premier <p> après <h2> */ h2 + p { font-size: 18px; font-weight: bold; }

4.3 Le sélecteur de frère général ~

Cible tous les frères suivants d'un élément (pas seulement le premier).

/* Cible tous les <p> qui suivent un <h2> au même niveau */ h2 ~ p { color: #555; }

4.4 Les sélecteurs d'attribut

Ils permettent de cibler des éléments en fonction de leurs attributs HTML.

Sélecteur Cible Exemple
[attr] Élément ayant l'attribut [disabled]
[attr="value"] Attribut égal à la valeur exacte [type="text"]
[attr^="value"] Attribut commençant par [href^="https"]
[attr$="value"] Attribut terminant par [href$=".pdf"]
[attr*="value"] Attribut contenant [href*="ofppt"]
<!-- HTML --> <a href="https://example.com">Lien HTTPS</a> <a href="document.pdf">PDF</a> /* Tous les liens sécurisés */ a[href^="https"] { color: green; } /* Tous les liens PDF */ a[href$=".pdf"] { color: red; font-weight: bold; }

4.5 Les pseudo-classes

Une pseudo-classe cible un élément dans un état particulier (survol, focus, clic, premier enfant, etc.). Elle s'écrit avec :.

Pseudo-classe Signification
:hover Au survol de la souris
:focus Élément sélectionné (input, lien)
:active Au moment du clic
:visited Lien déjà visité
:first-child Premier enfant de son parent
:last-child Dernier enfant de son parent
:nth-child(n) n-ième enfant (ex : :nth-child(2))
:not(selector) Tous sauf ceux qui correspondent
/* Changement de couleur au survol */ a:hover { color: orange; text-decoration: underline; } /* Style du premier élément d'une liste */ li:first-child { font-weight: bold; } /* Lignes impaires d'un tableau */ tr:nth-child(odd) { background: #f1faf4; }
✅ Usage fréquent : les pseudo-classes :hover et :focus sont incontournables pour améliorer l'interactivité et l'accessibilité d'un site.

4.6 Les pseudo-éléments

Un pseudo-élément cible une partie spécifique d'un élément (première lettre, première ligne, avant, après). Il s'écrit avec ::.

Pseudo-élément Signification
::before Insère du contenu avant l'élément
::after Insère du contenu après l'élément
::first-line Première ligne d'un texte
::first-letter Première lettre d'un texte
::selection Texte sélectionné par l'utilisateur
/* Ajoute une flèche devant chaque lien externe */ a.externe::after { content: " ↗"; color: #2e8b57; } /* Première lettre d'un paragraphe en grand */ p::first-letter { font-size: 2em; font-weight: bold; }

5. Mise en forme du texte

5.1 Les propriétés de police

Le CSS offre de nombreuses propriétés pour contrôler l'apparence du texte. Elles s'appliquent à la plupart des éléments contenant du texte (paragraphes, titres, liens, listes, etc.).

Propriété Rôle Valeurs possibles
font-family Police de caractères Arial, "Times New Roman", serif, sans-serif
font-size Taille de la police 16px, 1.2em, 1rem, 120%
font-weight Graisse (épaisseur) normal, bold, 100 à 900
font-style Style (italique) normal, italic, oblique
text-transform Transformation de la casse uppercase, lowercase, capitalize
text-decoration Décoration (souligné, barré) none, underline, line-through

5.2 La propriété font-family

Elle définit la police d'écriture. Il est recommandé de proposer plusieurs polices en cascade (au cas où la première n'est pas disponible).

/* Police simple */ body { font-family: Arial; } /* Cascade de polices (fallback) */ h1 { font-family: "Helvetica Neue", Helvetica, Arial, sans-serif; } /* Police système (rapide et moderne) */ p { font-family: system-ui, -apple-system, sans-serif; }
💡 Bonnes pratiques :
• Toujours terminer par une famille générique (serif, sans-serif, monospace)
• Les noms contenant des espaces doivent être entre guillemets ("Times New Roman")
• Limiter le nombre de polices à 2 ou 3 maximum par site

5.3 La propriété font-size

Elle définit la taille du texte. Les valeurs les plus courantes :

Unité Signification Exemple
pxPixels absolus16px
emRelatif à la taille du parent1.2em
remRelatif à la taille racine1.5rem
%Pourcentage du parent120%
/* Taille en pixels (simple, mais pas responsive) */ p { font-size: 16px; } /* Taille en rem (recommandé) */ h1 { font-size: 2rem; } /* 32px si racine = 16px */ h2 { font-size: 1.5rem; } /* 24px */ p { font-size: 1rem; } /* 16px */

5.4 Les propriétés d'alignement et d'espacement

Propriété Rôle Valeurs
text-align Alignement horizontal left, right, center, justify
line-height Hauteur de ligne 1.5, 24px, 150%
letter-spacing Espacement entre les lettres 1px, 0.05em
word-spacing Espacement entre les mots 2px, 0.1em
text-indent Retrait de la première ligne 20px, 1.5em
/* Texte centré avec bonne hauteur de ligne */ .centre { text-align: center; line-height: 1.6; } /* Titre espacé et en majuscules */ h1 { letter-spacing: 2px; text-transform: uppercase; } /* Paragraphe justifié avec retrait */ p { text-align: justify; text-indent: 20px; }

5.5 La propriété text-decoration

Très utilisée pour styliser les liens. Par défaut, les liens sont soulignés et bleus.

/* Retire le soulignement par défaut des liens */ a { text-decoration: none; color: #1d5e36; } /* Soulignement au survol */ a:hover { text-decoration: underline; } /* Texte barré (prix barré, par exemple) */ .prix-barre { text-decoration: line-through; color: #999; }

5.6 La propriété raccourcie font

Elle permet de regrouper plusieurs propriétés de police en une seule ligne.

/* Version longue */ p { font-style: italic; font-weight: bold; font-size: 16px; line-height: 1.5; font-family: Arial, sans-serif; } /* Version raccourcie (même résultat) */ p { font: italic bold 16px/1.5 Arial, sans-serif; }
⚠️ Attention : dans la propriété raccourcie font, l'ordre est imposé : style, weight, size/line-height, family. La taille et la famille sont obligatoires.

<!-- HTML --> <article> <h2>Mon article</h2> <p class="intro">Introduction en gras.</p> <p>Contenu normal de l'article.</p> <a href="#">Lire la suite</a> </article> /* CSS */ article { font-family: "Segoe UI", Arial, sans-serif; line-height: 1.6; } h2 { font-size: 1.8rem; font-weight: 700; color: #144a26; margin-bottom: 10px; } .intro { font-weight: bold; font-style: italic; color: #555; } a { color: #1d5e36; text-decoration: none; font-weight: 600; } a:hover { text-decoration: underline; }

6. Les unités de mesure

6.1 Pourquoi des unités de mesure ?

En CSS, chaque valeur numérique doit être accompagnée d'une unité de mesure (sauf pour certaines propriétés comme line-height ou z-index). Le choix de l'unité est crucial : il influence la réactivité, l'accessibilité et la maintenabilité du site.

💡 Idée clé : les unités absolues restent fixes, tandis que les unités relatives s'adaptent à un contexte (taille du parent, de la racine, de l'écran).

6.2 Les unités absolues

Elles ne dépendent d'aucun contexte. Elles sont fixes.

Unité Signification Usage
px Pixel (1/96e de pouce) Mise en forme classique
cm Centimètre Impression
mm Millimètre Impression
in Pouce (1 in = 2.54 cm) Impression
pt Point (1 pt = 1/72 in) Typographie, impression
/* Taille fixe (attention sur mobile) */ h1 { font-size: 32px; } p { font-size: 16px; }

6.3 Les unités relatives

Elles s'adaptent à un contexte de référence.

Unité Référence Usage typique
em Taille de police du parent Mise à l'échelle locale
rem Taille de police de la racine (<html>) Recommandé pour les tailles
% Pourcentage de la valeur du parent Largeurs, tailles
vw 1% de la largeur du viewport Éléments plein écran
vh 1% de la hauteur du viewport Sections plein écran
vmin 1% de la plus petite dimension du viewport Éléments adaptatifs
vmax 1% de la plus grande dimension du viewport Éléments adaptatifs
ch Largeur du caractère "0" Largeur de champs de saisie

6.4 Différence entre em et rem

C'est une question fondamentale en CSS.

/* Taille racine par défaut : 16px */ html { font-size: 16px; } /* Un <div> parent avec font-size 20px */ .parent { font-size: 20px; } /* .enfant hérite du parent */ .parent .enfant { font-size: 1.5em; /* 1.5 × 20px = 30px (basé sur le parent) */ } /* .enfant2 basé sur la racine */ .enfant2 { font-size: 1.5rem; /* 1.5 × 16px = 24px (basé sur <html>) */ }
✅ Règle simple : utilisez rem pour les tailles de police et les espacements (plus prévisible), et em pour les éléments qui doivent s'adapter à leur parent (boutons, badges, composants imbriqués).

6.5 Les unités de viewport vw et vh

Elles sont basées sur les dimensions de la fenêtre du navigateur (viewport). Elles sont idéales pour créer des sections plein écran.

/* Section qui occupe exactement tout l'écran */ .hero { width: 100vw; /* 100% de la largeur de l'écran */ height: 100vh; /* 100% de la hauteur de l'écran */ background: #1d5e36; color: white; display: flex; align-items: center; justify-content: center; } /* Taille de police fluide */ h1 { font-size: 4vw; /* 4% de la largeur de l'écran */ }
⚠️ Attention : sur mobile, 100vh peut poser problème (barres d'adresse). Préférez 100dvh (dynamic viewport height) sur les navigateurs récents.

6.6 Quand utiliser quelle unité ?

Élément Unité recommandée Raison
Taille du texte principal rem ou px Prévisible, respecte les préférences utilisateur
Marges et paddings rem ou em S'adapte à la taille de la police
Largeurs de conteneurs % ou max-width Responsive
Hauteur d'écran vh ou dvh Plein écran
Bordures fines px Précision
Largeur de champ de saisie ch Adaptée au contenu attendu

7. Couleurs et arrière-plans

7.1 Les quatre façons de définir une couleur

Le CSS propose plusieurs notations pour définir une couleur. Chacune a ses avantages selon le contexte d'utilisation.

Notation Exemple Usage
Nommée red, blue, green Tests rapides (140 noms disponibles)
HEX #1d5e36 Standard du web, compact
RGB / RGBA rgb(29, 94, 54) / rgba(29, 94, 54, 0.5) Transparence possible avec RGBA
HSL / HSLA hsl(145, 52%, 24%) Manipulation intuitive des teintes

7.2 La notation HEX

Elle commence par # suivi de 3, 6 ou 8 caractères hexadécimaux (0-9 et A-F). Chaque paire représente une composante Rouge-Vert-Bleu.

/* HEX sur 6 caractères (le plus courant) */ .titre { color: #1d5e36; } /* Vert foncé */ .texte { color: #333333; } /* Gris foncé */ /* HEX sur 3 caractères (raccourci quand les paires sont identiques) */ .blanc { color: #fff; } /* = #ffffff */ .noir { color: #000; } /* = #000000 */ /* HEX avec transparence (8 caractères) */ .overlay { background: #1d5e3680; /* Vert à 50% d'opacité */ }

7.3 La notation RGB et RGBA

RGB utilise trois valeurs (0-255) pour Rouge, Vert, Bleu. RGBA ajoute une quatrième valeur pour l'opacité (entre 0 et 1).

/* RGB — sans transparence */ .vert { color: rgb(29, 94, 54); } /* RGBA — avec transparence (0 = transparent, 1 = opaque) */ .vert-transparent { background: rgba(29, 94, 54, 0.5); } /* Un fond noir semi-transparent très utilisé */ .overlay { background: rgba(0, 0, 0, 0.6); }
💡 Astuce : RGBA est idéal pour les surcouches (overlays), les ombres et les fonds translucides.

7.4 La notation HSL et HSLA

HSL signifie Hue, Saturation, Lightness (Teinte, Saturation, Luminosité). C'est la notation la plus intuitive pour un designer.

Composante Valeurs Signification
H (Hue) 0 à 360° Position sur le cercle chromatique (0 = rouge, 120 = vert, 240 = bleu)
S (Saturation) 0% à 100% 0% = gris · 100% = couleur vive
L (Lightness) 0% à 100% 0% = noir · 50% = couleur pure · 100% = blanc
/* Vert naturel */ .vert { color: hsl(145, 52%, 24%); } /* Variante plus claire (même teinte, luminosité augmentée) */ .vert-clair { color: hsl(145, 52%, 60%); } /* Variante désaturée (gris verdâtre) */ .vert-gris { color: hsl(145, 10%, 24%); } /* HSLA avec transparence */ .overlay { background: hsla(145, 52%, 24%, 0.8); }
✅ Avantage de HSL : pour créer une palette cohérente, il suffit de garder la même teinte H et de faire varier S et L.

7.5 La propriété color

Elle définit la couleur du texte d'un élément.

/* Couleur du texte dans différents éléments */ body { color: #333; /* Texte principal gris foncé */ } h1 { color: #144a26; /* Titre en vert foncé */ } a { color: #1d6e3f; /* Liens en vert moyen */ } a:hover { color: #0f542f; /* Liens plus foncés au survol */ }

7.6 La propriété background-color

Elle définit la couleur de fond d'un élément.

/* Fond simple */ body { background-color: #f5f5f5; } .header { background-color: #1d5e36; color: white; } /* Fond transparent (utile pour superposer sur une image) */ .overlay { background-color: rgba(0, 0, 0, 0.5); }

7.7 La propriété background-image

Elle permet d'utiliser une image en arrière-plan.

/* Image de fond simple */ .hero { background-image: url("images/banner.jpg"); } /* Image de fond avec position et taille */ .hero { background-image: url("images/banner.jpg"); background-size: cover; /* Couvre tout l'élément */ background-position: center; /* Centré */ background-repeat: no-repeat; /* Ne se répète pas */ } /* Image répétée (motif) */ .motif { background-image: url("images/pattern.png"); background-repeat: repeat; }
Propriété Rôle Valeurs courantes
background-size Taille de l'image de fond auto, cover, contain, 100% 100%
background-position Position de l'image center, top left, 50% 50%
background-repeat Répétition de l'image no-repeat, repeat, repeat-x, repeat-y
background-attachment Comportement au défilement scroll, fixed

7.8 La propriété raccourcie background

Elle regroupe plusieurs propriétés d'arrière-plan en une seule ligne.

/* Version longue */ .hero { background-color: #1d5e36; background-image: url("banner.jpg"); background-repeat: no-repeat; background-position: center; background-size: cover; } /* Version raccourcie (même résultat) */ .hero { background: #1d5e36 url("banner.jpg") no-repeat center / cover; }

7.9 Les dégradés (gradients)

Les dégradés sont des arrière-plans générés par le navigateur, sans image externe. Ils sont très utilisés pour créer des effets modernes.

/* Dégradé linéaire vertical */ .hero { background: linear-gradient(#1d5e36, #2e8b57); } /* Dégradé horizontal */ .hero { background: linear-gradient(to right, #1d5e36, #a4d4b3); } /* Dégradé diagonal avec 3 couleurs */ .hero { background: linear-gradient(135deg, #144a26, #2e8b57, #a4d4b3); } /* Dégradé radial (cercle) */ .hero { background: radial-gradient(circle, #2e8b57, #144a26); }
⚠️ Compatibilité : les dégradés modernes sont supportés par tous les navigateurs récents. Plus besoin de préfixes -webkit-.

7.10 Choisir les bonnes couleurs

Le choix des couleurs influence la lisibilité et l'accessibilité d'un site. Il faut respecter les contrastes.

Gris foncé sur blanc Très bon ✅ Recommandé (#333)
Blanc sur vert foncé Très bon ✅ Idéal pour les boutons
Jaune sur blanc Très mauvais ❌ Illisible
Rouge sur bleu Mauvais ❌ À éviter

8. La cascade, l'héritage et la spécificité

8.1 Qu'est-ce que la cascade ?

Le mot cascade vient du nom complet du CSS : Cascading Style Sheets. Il désigne le mécanisme qui détermine quelle règle CSS s'applique lorsqu'il y a un conflit entre plusieurs règles qui ciblent le même élément.

💡 Analogie : imaginez plusieurs feuilles de style empilées. La règle qui se trouve « le plus haut » dans la pile gagne.

8.2 L'ordre d'application des styles

Quand plusieurs règles ciblent le même élément, l'ordre d'application est :

Priorité Source du style Exemple
1 (le plus faible) Style par défaut du navigateur Les liens sont bleus soulignés
2 Feuille de style externe <link rel="stylesheet">
3 Style interne <style> dans le <head>
4 Style inline <p style="color: red;">
5 (le plus fort) !important color: red !important;
⚠️ Attention : l'usage de !important est à éviter absolument sauf en dernier recours. Il casse la logique de la cascade et rend le code difficile à maintenir.

8.3 L'ordre d'apparition dans le fichier CSS

À priorité égale (par exemple, deux règles dans le même fichier CSS), la dernière déclarée gagne.

/* Deux règles ciblant le même élément */ p { color: blue; } p { color: red; } /* Le paragraphe sera ROUGE, car la 2ᵉ règle gagne */

8.4 L'héritage

Certaines propriétés CSS sont héritées automatiquement par les éléments enfants. D'autres ne le sont pas.

Propriétés héritées ✅ Propriétés NON héritées ❌
color margin
font-family padding
font-size border
line-height background
text-align width / height
<!-- HTML --> <body> <p>Ce texte hérite du style du body.</p> <div> <p>Ce texte aussi, tant qu'aucune règle ne le surcharge.</p> </div> </body> /* CSS */ body { font-family: Arial, sans-serif; color: #333; line-height: 1.6; } /* Les <p> héritent automatiquement de la police, de la couleur et de la hauteur de ligne */
✅ Bonne pratique : définir font-family, color et line-height sur le body est une excellente stratégie : tous les éléments en héritent et votre code est plus concis.

8.5 La spécificité

La spécificité est un score attribué à chaque sélecteur CSS. Plus le score est élevé, plus la règle est prioritaire en cas de conflit.

Sélecteur Valeur Exemple
Sélecteur universel 0 *
Sélecteur de balise 1 p, div, h1
Sélecteur de classe 10 .intro, .btn
Pseudo-classe 10 :hover, :first-child
Sélecteur d'attribut 10 [type="text"]
Sélecteur d'id 100 #header
Style inline 1000 style="..."
!important ∞ color: red !important;

8.6 Comment calculer la spécificité

La spécificité se note sous forme de quatre nombres : (inline, id, classe, balise).

/* Exemples de calcul */ p /* 0,0,0,1 → score 1 */ .intro /* 0,0,1,0 → score 10 */ p.intro /* 0,0,1,1 → score 11 */ #header /* 0,1,0,0 → score 100 */ #header .intro /* 0,1,1,0 → score 110 */ nav ul li a /* 0,0,0,4 → score 4 */ a:hover /* 0,0,1,1 → score 11 */

8.7 Exemple pratique de conflit

<!-- HTML --> <p id="intro" class="texte">Un paragraphe.</p> /* CSS — trois règles ciblent le même <p> */ p { color: blue; } /* spécificité : 1 */ .texte { color: green; } /* spécificité : 10 */ #intro { color: red; } /* spécificité : 100 */ /* Résultat : le paragraphe sera ROUGE (règle #intro gagne) */
⚠️ Règle d'or : évitez les id pour la mise en forme CSS courante. Utilisez des classes : elles sont plus flexibles et évitent les conflits de spécificité.

8.8 Comment éviter les conflits de spécificité

  • Utilisez des classes plutôt que des id pour styliser.
  • Évitez les sélecteurs trop profonds (ex : body div ul li a span).
  • Ne mélangez pas trop de niveaux (balise + classe + id).
  • N'abusez pas de !important : il casse la logique de la cascade.
  • Organisez votre CSS dans un ordre logique : reset, base, layout, composants, utilitaires.

8.9 Le mot-clé !important

Il force une déclaration à être prioritaire sur toutes les autres. Son usage est fortement déconseillé sauf cas exceptionnel.

/* Utilisation de !important */ p { color: red !important; /* Cette règle sera prioritaire sur TOUTES les autres */ } /* Même un id ne pourra pas la surcharger */ #intro { color: blue; /* Ne s'appliquera pas */ }
⚠️ À éviter : !important est souvent utilisé par des développeurs débutants pour « forcer » un style à s'appliquer. En réalité, cela masque un problème de spécificité mal géré. Préférez corriger la spécificité.

9. Le modèle de boîte

9.1 Qu'est-ce que le modèle de boîte ?

En CSS, chaque élément HTML est considéré comme une boîte rectangulaire. Le modèle de boîte (box model) décrit la structure de cette boîte, composée de quatre couches concentriques.

💡 Analogie : imaginez un tableau encadré et posé sur un mur. La peinture est le contenu, le cadre est la bordure, l'espace entre la peinture et le cadre est le padding, et l'espace entre le cadre et le mur est la marge.

9.2 Les 4 couches du modèle de boîte

Couche Propriété CSS Rôle
Contenu width, height Le texte, l'image ou tout autre contenu
Padding padding Espace intérieur (entre contenu et bordure)
Bordure border Le trait qui entoure le padding
Marge margin Espace extérieur (entre la boîte et les autres éléments)
/* Schéma visuel du modèle de boîte */ ┌─────────────────────────────────────┐ │ MARGIN (extérieur) │ │ ┌───────────────────────────────┐ │ │ │ BORDER (bordure) │ │ │ │ ┌─────────────────────────┐ │ │ │ │ │ PADDING (intérieur) │ │ │ │ │ │ ┌───────────────────┐ │ │ │ │ │ │ │ CONTENU │ │ │ │ │ │ │ └───────────────────┘ │ │ │ │ │ └─────────────────────────┘ │ │ │ └───────────────────────────────┘ │ └─────────────────────────────────────┘

9.3 La propriété width et height

Elles définissent la largeur et la hauteur de la zone de contenu (pas la boîte totale).

/* Dimensions fixes */ .boite { width: 300px; height: 200px; } /* Dimensions relatives (recommandé) */ .conteneur { width: 80%; /* 80% du parent */ max-width: 1200px; /* Plafonné à 1200px */ min-height: 200px; /* Au moins 200px de haut */ } /* Dimensions automatiques */ .auto { width: auto; /* Calculé par le navigateur */ }

9.4 La propriété padding

Elle définit l'espace intérieur, entre le contenu et la bordure.

/* Padding uniforme */ .boite { padding: 20px; /* 20px sur les 4 côtés */ } /* Padding différencié (haut droite bas gauche) */ .boite { padding: 10px 20px 15px 25px; } /* Padding vertical / horizontal */ .boite { padding: 10px 20px; /* 10px haut/bas, 20px gauche/droite */ } /* Padding par côté */ .boite { padding-top: 10px; padding-right: 20px; padding-bottom: 15px; padding-left: 25px; }

9.5 La propriété margin

Elle définit l'espace extérieur, entre la boîte et les autres éléments.

/* Marge uniforme */ .boite { margin: 20px; } /* Marge différenciée (haut droite bas gauche) */ .boite { margin: 10px 20px 15px 25px; } /* Centrer horizontalement un bloc */ .centre { width: 600px; margin: 0 auto; /* 0 en haut/bas, auto en gauche/droite */ } /* Marge négative (pour chevaucher) */ .chevauchement { margin-top: -20px; }

9.6 La propriété border

Elle définit la bordure autour de l'élément. Elle se compose de trois caractéristiques : largeur, style, couleur.

dashedLigne en tirets

9.7 Le calcul de la largeur totale (sans box-sizing)

Par défaut, width ne concerne que la zone de contenu. La largeur totale est la somme du contenu, du padding et de la bordure.

/* Sans box-sizing */ .boite { width: 300px; padding: 20px; border: 5px solid #000; } /* Largeur totale calculée : */ /* 300 (contenu) + 20×2 (padding) + 5×2 (bordure) = 350px */
⚠️ Piège fréquent : un élément avec width: 100% et un padding dépasse souvent son conteneur, car le padding s'ajoute à la largeur.

9.8 La propriété box-sizing

Elle permet de changer le calcul de la largeur. La valeur border-box fait que width inclut le padding et la bordure.

/* Comportement par défaut (content-box) */ .boite { box-sizing: content-box; /* width = contenu uniquement */ } /* Recommandé : border-box */ .boite { box-sizing: border-box; /* width = contenu + padding + bordure */ } /* Reset global recommandé */ *, *::before, *::after { box-sizing: border-box; }
✅ Bonne pratique universelle : appliquez box-sizing: border-box à tous les éléments avec le sélecteur universel. Cela évite les mauvaises surprises.

9.9 La propriété overflow

Elle gère le comportement du contenu qui dépasse les dimensions de la boîte.

Valeur Comportement

hiddenLe contenu qui dépasse est masqué
scrollBarres de défilement toujours visibles
autoBarres de défilement si nécessaire
/* Conteneur à hauteur fixe avec défilement */ .conteneur { width: 300px; height: 200px; overflow: auto; } /* Masquer le débordement */ .masque { overflow: hidden; }

9.10 Les collisions de marges (margin collapse)

Quand deux marges verticales se rencontrent, elles ne s'additionnent pas : la plus grande gagne. C'est un comportement spécifique du CSS.

/* Deux paragraphes consécutifs */ p { margin-top: 20px; margin-bottom: 30px; } /* L'espace entre deux <p> ne sera PAS 50px */ /* Ce sera 30px (la plus grande des deux) */
⚠️ Important : la collision de marges ne concerne que les marges verticales et uniquement pour des éléments en flux normal. Elle ne s'applique pas en Flexbox ou Grid.

10. Positionnement et affichage

10.1 La propriété display

Elle définit comment un élément est affiché et comment il se comporte vis-à-vis des autres éléments.

Valeur Comportement Exemples d'éléments
block Occupe toute la largeur, saut de ligne avant/après div, p, h1
inline S'insère dans le flux du texte, pas de saut de ligne span, a, strong
inline-block Comme inline mais accepte width/height img, boutons
none Élément invisible (retiré du flux) —
flex Conteneur flexbox —
grid Conteneur grid —
/* Transformer un élément inline en block */ a { display: block; /* Les liens se comportent comme des blocs */ padding: 10px; background: #1d5e36; } /* Afficher des éléments côte à côte */ li { display: inline-block; margin-right: 15px; } /* Masquer un élément (mais il est retiré du flux) */ .cache { display: none; }
📌 display: none vs visibility: hidden :
• display: none → l'élément est retiré complètement du flux.
• visibility: hidden → l'élément est invisible mais conserve sa place.

10.2 La propriété position

Elle définit la méthode de positionnement d'un élément dans la page.

Valeur Comportement Référence
static (défaut) Flux normal Aucune
relative Décalé par rapport à sa position normale Sa position d'origine
absolute Retiré du flux, positionné librement Le parent positionné le plus proche
fixed Retiré du flux, reste fixe au défilement La fenêtre du navigateur
sticky Se comporte comme relative, puis fixed après un seuil Le scroll

🔹 position: relative

L'élément reste dans le flux, mais peut être décalé.

.decale { position: relative; top: 10px; /* Décalé de 10px vers le bas */ left: 20px; /* Décalé de 20px vers la droite */ }

🔹 position: absolute

L'élément est retiré du flux. Il est positionné par rapport à son parent le plus proche positionné (avec position: relative, absolute, fixed ou sticky).

/* Parent positionné */ .parent { position: relative; width: 300px; height: 200px; } /* Enfant positionné en haut à droite */ .enfant { position: absolute; top: 0; right: 0; } /* Centrer un élément absolu */ .centre-absolu { position: absolute; top: 50%; left: 50%; transform: translate(-50%, -50%); }

🔹 position: fixed

L'élément reste fixe par rapport à la fenêtre, même au défilement.

/* Barre de navigation fixe en haut */ .navbar { position: fixed; top: 0; left: 0; width: 100%; background: #1d5e36; color: white; padding: 15px; z-index: 1000; } /* Bouton "retour en haut" fixe en bas à droite */ .btn-top { position: fixed; bottom: 20px; right: 20px; }

🔹 position: sticky

L'élément se comporte comme relative puis devient fixed une fois un seuil atteint.

/* En-tête collant au défilement */ .header-sticky { position: sticky; top: 0; background: white; z-index: 100; }

10.3 La propriété z-index

Elle définit l'ordre d'empilement des éléments positionnés. Plus le z-index est élevé, plus l'élément est au-dessus.

.arriere-plan { position: absolute; z-index: 1; } .contenu { position: absolute; z-index: 10; /* Au-dessus */ } .modal { position: fixed; z-index: 9999; /* Au premier plan */ }
⚠️ Important : le z-index ne fonctionne que sur les éléments positionnés (relative, absolute, fixed, sticky). Il n'a aucun effet sur static.

10.4 La propriété float

Elle permet de faire flotter un élément à gauche ou à droite, permettant au texte de l'entourer.

/* Image qui flotte à droite */ img { float: right; margin: 0 0 10px 20px; } /* Annuler le float */ .clear { clear: both; }
⚠️ Avertissement : float est aujourd'hui rarement utilisé pour la mise en page. On lui préfère Flexbox ou Grid, plus modernes et plus puissants. float reste utile pour les cas spécifiques (image entourée de texte).

10.5 Aperçu de Flexbox

Flexbox est un système de mise en page moderne qui simplifie l'alignement des éléments sur un axe.

/* Conteneur flex */ .conteneur { display: flex; justify-content: space-between; /* Axe horizontal */ align-items: center; /* Axe vertical */ gap: 20px; /* Espace entre les enfants */ } /* Colonne verticale */ .colonne { display: flex; flex-direction: column; }
📌 À retenir : Flexbox sera étudié en détail dans un chapitre dédié. Cette section se contente d'une introduction.
