1. Qu'est-ce que le CSS ?

1.1 Définition

CSS signifie Cascading Style Sheets (Feuilles de Style en Cascade). C'est un langage de description qui permet de définir la présentation (l'apparence visuelle) d'un document HTML : couleurs, polices, tailles, espacements, positions, animations, etc.

💡 En résumé : le HTML structure le contenu (le fond), le CSS met en forme ce contenu (la forme).

1.2 Le rôle du CSS dans une page web

Le CSS intervient à plusieurs niveaux :

  • Mise en forme du texte : polices, couleurs, tailles, alignements
  • Mise en page : disposition des blocs, colonnes, grilles, marges
  • Couleurs et arrière-plans : fonds de page, dégradés, transparences
  • Effets visuels : ombres, bordures arrondies, transitions, animations
  • Adaptation aux écrans : responsive design (mobile, tablette, ordinateur)

1.3 L'architecture d'une page web moderne

Une page web bien conçue repose sur trois piliers :

Technologie Rôle Analogie
HTML Structure et contenu Le squelette d'une maison
CSS Présentation et mise en forme La peinture et la décoration
JavaScript Interactivité et dynamisme L'électricité et les automatismes

1.4 Les avantages du CSS

  • Séparation du fond et de la forme : le contenu HTML reste pur, le style est isolé dans un fichier CSS.
  • Réutilisabilité : une seule feuille de style peut s'appliquer à des centaines de pages.
  • Maintenance facile : modifier une couleur sur tout un site en changeant une seule ligne.
  • Performances : le navigateur met en cache le fichier CSS, réduisant le temps de chargement.
  • Accessibilité : possibilité d'adapter l'affichage aux besoins (malvoyants, mobiles).

2. Syntaxe CSS et modes d'intégration

2.1 La syntaxe d'une règle CSS

Une règle CSS se compose de trois éléments :

/* Structure d'une règle CSS */
selecteur {
  propriete: valeur;
  autre-propriete: autre-valeur;
}
Élément Rôle Exemple
Sélecteur Cible les éléments HTML à styliser p, .intro, #header
Propriété Aspect à modifier color, font-size, margin
Valeur Valeur à appliquer red, 16px, 10px

2.2 Exemple de règle CSS complète

💻 Code 👁️ Rendu 
p {
  color: #333333;
  font-size: 16px;
  line-height: 1.6;
  margin-bottom: 15px;
}

Ce paragraphe applique la règle CSS ci-contre. La couleur est gris foncé, la taille de 16px et la hauteur de ligne de 1.6.

Ce deuxième paragraphe reçoit les mêmes styles grâce au sélecteur p.

📌 Règles d'écriture :
• Chaque déclaration se termine par un point-virgule ;
• Le bloc de déclarations est entouré d'accolades { }
• Les commentaires sont entre /* ... */

2.3 Les trois modes d'intégration du CSS

🔹 Mode 1 · CSS en ligne (inline)

Le style est directement écrit dans la balise HTML via l'attribut style.

💻 Code 👁️ Rendu 
<p style="color: #1d5e36; font-size: 18px;">
  Ce paragraphe utilise le CSS inline.
</p>

Ce paragraphe utilise le CSS inline.

⚠️ À éviter : le CSS inline est difficile à maintenir. À réserver aux tests rapides ou aux cas très spécifiques (emails HTML).

🔹 Mode 2 · CSS interne (embedded)

Le style est écrit dans une balise <style> dans la partie <head>.

💻 Code 
<head>
  <style>
    p {
      color: #2e8b57;
      font-size: 16px;
      font-weight: bold;
    }
  </style>
</head>
<body>
  <p>Ce paragraphe est stylisé via le CSS interne.</p>
</body>
👁️ Rendu

Ce paragraphe est stylisé via le CSS interne.

🔹 Mode 3 · CSS externe (recommandé)

Le style est écrit dans un fichier séparé avec l'extension .css, puis lié au HTML via la balise <link>.

💻 index.html 
<head>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <p>Ce paragraphe utilise le CSS externe.</p>
</body>
💻 style.css 
p {
  color: #144a26;
  font-size: 16px;
  font-style: italic;
}
👁️ Rendu

Ce paragraphe utilise le CSS externe.

✅ Bonne pratique : c'est la méthode recommandée pour tout site professionnel. Un seul fichier CSS peut être partagé par toutes les pages.

3. Les sélecteurs de base

3.1 Qu'est-ce qu'un sélecteur CSS ?

Un sélecteur CSS est un motif qui permet de cibler un ou plusieurs éléments HTML dans le but de leur appliquer un style.

💡 Analogie : un sélecteur CSS fonctionne comme un filtre. Il dit « je veux uniquement les éléments qui correspondent à ce critère ».

3.2 Les 4 sélecteurs fondamentaux

Sélecteur Syntaxe Cible
Universel * Tous les éléments
Balise element Toutes les balises du type
Classe .nom-classe Tous les éléments portant la classe
Identifiant #nom-id L'élément unique portant l'id

🔹 Le sélecteur universel *

Cible tous les éléments de la page. Souvent utilisé pour un reset global.

💻 Code 
* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}
👁️ Effet

Toutes les marges et paddings par défaut sont supprimés. (L'effet est invisible ici car les éléments sont déjà dans un conteneur avec marges contrôlées.)

⚠️ Attention : le sélecteur universel peut être coûteux en performance sur de très grosses pages. À utiliser avec discernement.

🔹 Le sélecteur de balise

Cible toutes les balises d'un type donné dans le document.

💻 Code 👁️ Rendu 
p {
  color: #1d5e36;
  font-size: 17px;
  line-height: 1.8;
}

a {
  color: #2e8b57;
  text-decoration: none;
}

Tous les paragraphes de la page reçoivent ces styles grâce au sélecteur p.

🔹 Le sélecteur de classe

En HTML, une classe se déclare avec l'attribut class. En CSS, on la cible avec un point ..

💻 Code HTML 
<p class="intro">Ce paragraphe est stylisé.</p>
<p>Ce paragraphe reste normal.</p>
💻 Code CSS 
.intro {
  font-size: 18px;
  font-weight: bold;
  color: #2e8b57;
}
👁️ Rendu

Ce paragraphe reste normal.

✅ Bonne pratique : les classes sont la méthode la plus utilisée en CSS moderne. Elles sont réutilisables sur plusieurs éléments.

🔹 Le sélecteur d'identifiant

En HTML, un identifiant se déclare avec l'attribut id. En CSS, on le cible avec un dièse #.

💻 Code 👁️ Rendu 
#header {
  background: #1d5e36;
  color: white;
  padding: 20px;
  text-align: center;
  border-radius: 8px;
}
En-tête principal (id="header")
⚠️ Règle W3C : un identifiant id doit être unique dans toute la page. Deux éléments ne peuvent pas porter le même id.

En CSS, chaque élément HTML est considéré comme une boîte rectangulaire. Cette boîte est composée de quatre couches emboîtées les unes dans les autres.

Une animation CSS permet de faire évoluer un élément selon une séquence définie par des étapes clés (@keyframes).

💻 Code 
@keyframes pulsation {
  0%   { transform: scale(1);   opacity: 1; }
  50%  { transform: scale(1.1); opacity: 0.8; }
  100% { transform: scale(1);   opacity: 1; }
}

.pulse {
  animation: pulsation 2s infinite ease-in-out;
  background: #2e8b57;
  color: white;
  padding: 15px 30px;
  border-radius: 30px;
  font-weight: 700;
  display: inline-block;
}
