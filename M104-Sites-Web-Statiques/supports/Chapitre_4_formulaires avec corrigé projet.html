1. Anatomie d'un formulaire

1.1 La balise <form>

Un formulaire HTML est un conteneur qui regroupe des champs de saisie. Il est délimité par la balise <form> et possède plusieurs attributs essentiels.

<form action="/traitement.php" method="post">
  <!-- Champs du formulaire -->
</form>

1.2 Les attributs de <form>

AttributRôleValeurs possibles
actionURL de destination des donnéesChemin relatif ou absolu
methodMéthode d'envoi HTTPget ou post
enctypeEncodage des donnéesapplication/x-www-form-urlencoded, multipart/form-data
nameNom du formulaireChaîne de caractères
targetOù afficher la réponse_blank, _self, etc.
novalidateDésactive la validation HTML5Présence (booléen)
📌 Différence GET vs POST :
• GET : les données sont visibles dans l'URL, limitées en taille, utilisées pour les recherches.
• POST : les données sont envoyées dans le corps de la requête, plus sécurisées, utilisées pour les inscriptions.
Consigne : Écrivez la balise <form> pour un formulaire de contact qui envoie les données vers traitement.php en méthode POST.
⏳ 30 s
💡 Solution :
<form action="traitement.php" method="post">
  <!-- Champs à ajouter -->
</form>

2. Champs de saisie essentiels

La balise <input> est auto-fermante. Son attribut type détermine le type de champ affiché.

2.1 Champ texte : type="text"

💻 Code 👁️ Rendu 
<label for="nom">Nom :</label>
<input type="text" id="nom" name="nom"
       placeholder="Votre nom" maxlength="50">

2.2 Champ email : type="email"

💻 Code 👁️ Rendu 
<label for="email">Email :</label>
<input type="email" id="email" name="email"
       placeholder="vous@exemple.com">

2.3 Champ mot de passe : type="password"

💻 Code 👁️ Rendu 
<label for="mdp">Mot de passe :</label>
<input type="password" id="mdp" name="mdp"
       placeholder="••••••••">

2.4 Champ nombre : type="number"

💻 Code 👁️ Rendu 
<label for="age">Âge :</label>
<input type="number" id="age" name="age"
       min="18" max="99" step="1">

2.5 Champ date : type="date"

💻 Code 👁️ Rendu 
<label for="naissance">Date de naissance :</label>
<input type="date" id="naissance" name="naissance"
       min="1900-01-01" max="2025-12-31">

2.6 Champ fichier : type="file"

💻 Code 👁️ Rendu 
<label for="cv">CV (PDF) :</label>
<input type="file" id="cv" name="cv"
       accept=".pdf,.doc,.docx">
⚠️ Important : pour l'envoi de fichiers, le formulaire doit avoir enctype="multipart/form-data" et method="post".

4. Validation HTML5

HTML5 intègre une validation native côté client. Le navigateur vérifie automatiquement certaines contraintes avant l'envoi du formulaire.

4.1 Attributs de validation

AttributRôleExemple
requiredChamp obligatoire<input required>
patternExpression régulièrepattern="[0-9]{5}"
min / maxValeurs minimales et maximalesmin="0" max="100"
minlength / maxlengthLongueur du texteminlength="3" maxlength="20"
stepPas d'incrémentationstep="0.01"
placeholderTexte indicatifplaceholder="Votre nom"
autocompleteSuggestions de saisieautocomplete="email"
autofocusFocus automatique<input autofocus>
disabledChamp désactivé<input disabled>
readonlyChamp en lecture seule<input readonly>

4.2 Exemple de validation complète

💻 Code 👁️ Rendu 
<form>
  <label for="cp">Code postal (5 chiffres) :</label>
  <input type="text" id="cp" name="cp"
         required pattern="[0-9]{5}"
         title="5 chiffres exactement"
         placeholder="75001">

  <label for="satisfaction">Satisfaction (0 à 10) :</label>
  <input type="number" id="satisfaction" name="satisfaction"
         min="0" max="10" step="1" value="5">

  <label for="pseudo">Pseudo (3 à 15 caractères) :</label>
  <input type="text" id="pseudo" name="pseudo"
         minlength="3" maxlength="15" required>

  <button type="submit">Valider</button>
</form>
💡 Astuce : l'attribut title s'affiche dans une info-bulle lorsque la validation échoue, expliquant le format attendu.
Consigne : Ajoutez les attributs de validation appropriés au champ suivant pour qu'il accepte uniquement un numéro de téléphone marocain au format 06XXXXXXXX (10 chiffres commençant par 06).
⏳ 60 s
💡 Solution :
<label for="tel">Téléphone :</label>
<input type="tel" id="tel" name="tel"
       required
       pattern="^06[0-9]{8}$"
       title="Format : 06XXXXXXXX (10 chiffres)"
       placeholder="0612345678">

5. Structure et accessibilité

5.1 Grouper les champs : <fieldset> et <legend>

La balise <fieldset> permet de regrouper des champs apparentés. La balise <legend> donne un titre à ce groupe.

💻 Code 👁️ Rendu 
<fieldset>
  <legend>Informations personnelles</legend>

  <label for="prenom">Prénom :</label>
  <input type="text" id="prenom" name="prenom">

  <label for="nom2">Nom :</label>
  <input type="text" id="nom2" name="nom2">
</fieldset>
Informations personnelles

5.2 Accessibilité : l'élément <label>

L'élément <label> améliore l'accessibilité en associant un texte descriptif à un champ. Deux méthodes :

  • Avec for et id : <label for="email">Email</label><input id="email">
  • Par imbrication : <label>Email <input></label>
⚠️ Règle W3C : chaque champ de formulaire doit être associé à une étiquette <label>. Cela permet aux lecteurs d'écran de décrire le champ et améliore l'ergonomie (clic sur le label = focus sur le champ).

5.3 Attributs d'accessibilité

AttributRôle
aria-labelÉtiquette invisible pour les lecteurs d'écran
aria-describedbyRéférence à un texte descriptif
roleRôle de l'élément (ex : role="search")
Consigne : Corrigez ce code pour le rendre accessible :
<input type="text" placeholder="Nom">
⏳ 30 s
💡 Solution :
<label for="nom">Nom :</label>
<input type="text" id="nom" name="nom" placeholder="Votre nom">
Le placeholder ne remplace pas le <label> : il disparaît à la saisie.

7. Bonnes pratiques & pièges à éviter

7.1 Les 10 bonnes pratiques d'un formulaire HTML5

#Bonne pratiquePourquoi ?
1Toujours associer un <label> à chaque champAccessibilité (lecteurs d'écran)
2Utiliser le bon type d'<input>Clavier adapté sur mobile
3Grouper les champs apparentés avec <fieldset>Lisibilité et logique
4Préférer method="post" pour les données sensiblesSécurité (URL invisible)
5Utiliser required plutôt qu'un astérisque visuelValidation native automatique
6Fournir un placeholder en complément (jamais en remplacement) du labelErgonomie
7Ajouter enctype="multipart/form-data" pour les fichiersObligatoire sinon envoi échoue
8Limiter la longueur avec minlength et maxlengthPrévention des abus
9Utiliser autocomplete pour les champs standardsGain de temps utilisateur
10Valider côté client et côté serveurLa validation HTML5 est contournable

7.2 Pièges fréquents

⚠️ Piège 1 — Placeholder utilisé comme label
<input placeholder="Nom"> ❌ le texte disparaît à la saisie.
<label for="n">Nom</label><input id="n" placeholder="Votre nom"> ✅
⚠️ Piège 2 — Boutons radio sans name commun
Si les boutons radio n'ont pas le même name, ils ne forment pas un groupe : on peut en cocher plusieurs.
⚠️ Piège 3 — Oublier enctype pour les fichiers
Sans enctype="multipart/form-data", le fichier n'est jamais transmis.
⚠️ Piège 4 — Confondre id et name
id sert au label (association visuelle), name sert au serveur (clé de la donnée envoyée).
💡 Astuce pro : ouvrez toujours la console du navigateur (F12) pour observer les données envoyées dans l'onglet Network lors de la soumission d'un formulaire.

    <!-- CV -->
    <label for="cv">CV (PDF uniquement) :</label>
    <input type="file" id="cv" name="cv" accept=".pdf">

    <!-- CONDITIONS -->
    <label>
      <input type="checkbox" name="conditions" required>
      J'accepte les conditions d'utilisation
    </label>

    <!-- BOUTONS -->
    <input type="submit" value="Envoyer">
    <input type="reset" value="Réinitialiser">

  </form>

</body>
</html>
✅ Points clés de la solution :
• <!DOCTYPE html>, <html lang="fr">, <head> avec <title>
• <form> avec action, method="post" et enctype="multipart/form-data"
• Organisation en <fieldset> avec <legend>
• Chaque champ associé à un <label> avec for et id
• Validation native : required, pattern, minlength
• Boutons radio avec même name
• Cases à cocher pour les centres d'intérêt
• <textarea> avec minlength
• Upload de fichier avec accept=".pdf"
• Case à cocher obligatoire pour les conditions
• Boutons submit et reset
