1. Qu'est-ce que Flexbox ?

1.1 Définition

Flexbox (pour Flexible Box Layout) est un modèle de mise en page CSS introduit avec CSS3. Il permet de disposer, aligner et distribuer l'espace entre les éléments d'un conteneur de manière flexible et efficace, même lorsque leurs tailles sont inconnues ou dynamiques.

💡 Analogie : imaginez une rangée de livres sur une étagère. Flexbox, c'est la capacité de répartir automatiquement ces livres dans l'espace disponible, en les centrant, les espaçant ou les étirant selon vos besoins.

1.2 Pourquoi Flexbox ?

Avant Flexbox, les développeurs utilisaient des techniques fragiles :

  • float : provoquait des effets de bord et nécessitait des clearfix
  • inline-block : créait des espaces indésirables entre les éléments
  • table : rigide et sémantiquement incorrecte
  • Positionnement absolu : complexe à maintenir

Flexbox résout tous ces problèmes avec une syntaxe simple et moderne.

1.3 Les avantages de Flexbox

AvantageDescription
SimplicitéUne seule propriété (display: flex) active tout le système
FlexibilitéLes éléments s'adaptent automatiquement à l'espace disponible
Alignement facileCentrage vertical et horizontal en 2 lignes de CSS
Ordre personnalisableRéorganisation visuelle sans toucher au HTML
Responsive natifIdéal pour les mises en page adaptatives
Support universelCompatible avec tous les navigateurs modernes

Flexbox repose sur un principe fondamental : deux axes perpendiculaires.

1.5 Quand utiliser Flexbox ?

  • Alignement d'éléments dans une seule dimension (ligne ou colonne)
  • Navigation (menu horizontal ou vertical)
  • Centrage parfait (horizontal + vertical)
  • Répartition d'espace entre plusieurs éléments
  • Cartes de même hauteur
  • Barre latérale + contenu principal
  • Pied de page multi-colonnes
✅ À retenir : Flexbox est idéal pour les mises en page 1D (une seule direction). Pour les mises en page 2D (lignes et colonnes simultanées), on utilise plutôt CSS Grid.

2. Le conteneur flex

2.1 Activation du mode flex

Pour activer Flexbox, il suffit d'appliquer display: flex à un élément. Cet élément devient le conteneur flex, et tous ses enfants directs deviennent des éléments flex.

.conteneur { display: flex; }
📌 Important : seuls les enfants directs du conteneur flex deviennent des éléments flex. Les petits-enfants ne sont pas affectés.

2.2 display: flex vs display: inline-flex

Comme pour block et inline-block, Flexbox propose deux variantes :

ValeurComportementUsage
display: flex Le conteneur prend toute la largeur disponible (bloc) Mise en page principale
display: inline-flex Le conteneur prend la largeur de son contenu (inline) Composant intégré dans du texte
/* Le conteneur prend toute la largeur */ .flex-block { display: flex; } /* Le conteneur prend juste la largeur de son contenu */ .flex-inline { display: inline-flex; }

2.3 Le comportement par défaut

Quand on active display: flex, voici ce qui se produit automatiquement :

ComportementValeur par défaut
Directionrow (horizontal, de gauche à droite)
Alignement principalflex-start (à gauche)
Alignement secondairestretch (étiré sur toute la hauteur)
Retour à la lignenowrap (pas de retour)
OrdreOrdre du HTML

2.4 Les enfants flex

Un enfant flex perd son comportement natif. Par exemple, un <div> (normalement display: block) devient un élément flex sur une seule ligne.

/* HTML */ <div class="conteneur"> <div>Bloc 1</div> <div>Bloc 2</div> <div>Bloc 3</div> </div> /* CSS */ .conteneur { display: flex; } /* Les 3 div s'alignent sur la même ligne */

2.5 Les marges automatiques (astuce)

Flexbox permet une astuce très puissante : margin: auto sur un enfant flex pousse cet élément à absorber tout l'espace disponible.

/* Pousser un élément à droite */ .logo { margin-right: auto; /* Prend tout l'espace à droite */ } /* Centrer un élément */ .centre { margin: auto; /* Prend tout l'espace autour */ }

3.3 Impact sur les axes

📌 Point crucial : quand on change flex-direction, les axes sont inversés :
• En row : axe principal = horizontal, axe secondaire = vertical
• En column : axe principal = vertical, axe secondaire = horizontal

Cela signifie que justify-content et align-items échangent leurs rôles.
flex-directionjustify-content agit sur…align-items agit sur…
rowHorizontalVertical
columnVerticalHorizontal

3.4 Cas d'usage courants

  • row : navigation, cartes côte à côte, footer multi-colonnes
  • column : menu vertical, formulaires, listes, sections empilées
  • row-reverse : rare, mais utile pour inverser visuellement sans changer le HTML
  • column-reverse : chat (messages récents en haut), timelines

3.5 Exemple pratique : menu vertical

/* HTML */ <nav class="menu-vertical"> <a href="#">Accueil</a> <a href="#">Services</a> <a href="#">Contact</a> </nav> /* CSS */ .menu-vertical { display: flex; flex-direction: column; gap: 10px; width: 200px; }

1. flex-direction: row; avec HTML : 1, 2, 3, 4
2. flex-direction: row-reverse; avec HTML : 1, 2, 3, 4
3. flex-direction: column; avec HTML : 1, 2, 3, 4
4. flex-direction: column-reverse; avec HTML : 1, 2, 3, 4
5. flex-direction: column; avec HTML : 4, 3, 2, 1
6. flex-direction: row-reverse; avec HTML : 4, 3, 2, 1

4.3 Différence entre space-between, space-around et space-evenly

📌 Comprendre la différence :
• space-between : le premier élément est collé au début, le dernier à la fin. Aucun espace aux extrémités.
• space-around : chaque élément a un espace égal de chaque côté. Les extrémités ont un demi-espace.
• space-evenly : tous les espaces (extrémités incluses) sont strictement identiques.
/* Les 3 méthodes pour espacer */ .space-between { justify-content: space-between; } .space-around { justify-content: space-around; } .space-evenly { justify-content: space-evenly; }

5.3 Le centrage parfait (astuce classique)

En combinant justify-content: center et align-items: center, on obtient un centrage parfait horizontal et vertical en 2 lignes.

/* Centrage parfait en 2 lignes */ .centre-parfait { display: flex; justify-content: center; /* Horizontal */ align-items: center; /* Vertical */ min-height: 100vh; /* Pleine hauteur pour tester */ }

✅ Astuce : c'est la méthode la plus simple et moderne pour centrer un élément dans une page. Elle remplace toutes les techniques anciennes (table, position absolue + translate, etc.).

6. Le retour à la ligne (flex-wrap / align-content)

6.1 Le problème du débordement

Par défaut, Flexbox dispose tous les enfants sur une seule ligne, même si cela provoque un débordement horizontal (les éléments rétrécissent ou débordent du conteneur).

📌 Comportement par défaut : flex-wrap: nowrap — les éléments restent sur une seule ligne et peuvent se compresser ou déborder.

6.2 La propriété flex-wrap

wrap-reverseComme wrap, mais les nouvelles lignes vont vers le haut
/* Autoriser le retour à la ligne */ .galerie { display: flex; flex-wrap: wrap; /* Retour à la ligne automatique */ gap: 20px; }

6.3 La propriété align-content

Quand flex-wrap: wrap est activé et qu'il y a plusieurs lignes, la propriété align-content contrôle la répartition verticale de ces lignes.

⚠️ Attention : align-content ne fonctionne que s'il y a plusieurs lignes (donc avec flex-wrap: wrap et un débordement effectif).
ValeurEffet
stretch (défaut)Les lignes s'étirent sur toute la hauteur
flex-startLignes groupées en haut
flex-endLignes groupées en bas
centerLignes centrées verticalement
space-betweenPremière en haut, dernière en bas, espace entre
space-aroundEspace égal autour de chaque ligne
space-evenlyEspace strictement égal
/* Plusieurs lignes réparties uniformément */ .galerie { display: flex; flex-wrap: wrap; align-content: space-between; height: 400px; }

6.4 Différence entre align-items et align-content

PropriétéCibleCondition
align-itemsLes enfants dans une même ligneToujours actif
align-contentLes lignes entre ellesUniquement avec flex-wrap: wrap + plusieurs lignes

6.5 La propriété raccourcie flex-flow

Combine flex-direction et flex-wrap en une seule ligne.

/* Version longue */ .conteneur { flex-direction: row; flex-wrap: wrap; } /* Version raccourcie (même résultat) */ .conteneur { flex-flow: row wrap; }

6.6 Cas d'usage

  • Galerie d'images : wrap pour passer à la ligne automatiquement
  • Cartes de produits : wrap pour s'adapter à la largeur de l'écran
  • Badges / tags : wrap pour revenir à la ligne
  • Menu responsive : wrap pour passer en colonne sur mobile
Consigne : Un conteneur de 500px contient 6 blocs de 200px chacun.

1. Avec flex-wrap: nowrap, que se passe-t-il ?
2. Avec flex-wrap: wrap, combien de lignes y a-t-il ?
3. Avec flex-wrap: wrap-reverse, où vont les nouvelles lignes ?
4. Avec flex-wrap: wrap et align-content: center, comment sont positionnées les lignes ?
5. Quelle est la différence entre align-items et align-content ?
6. align-content fonctionne-t-il avec flex-wrap: nowrap ?
⏳ 60 s
💡 Solution :
1. Les 6 blocs de 200px sont compressés sur une seule ligne (ils rétrécissent ou débordent)
2. Avec wrap : 3 lignes de 2 blocs (2 × 200px = 400px, ce qui laisse la place pour un 2ᵉ bloc)
3. Avec wrap-reverse : les nouvelles lignes se placent au-dessus de la précédente
4. Les lignes sont centrées verticalement dans le conteneur
5. align-items aligne les éléments dans une ligne ; align-content aligne les lignes entre elles
6. Non, align-content ne fonctionne qu'avec plusieurs lignes (donc wrap)
Consigne : Créez une galerie d'images responsive avec :

• Un conteneur display: flex avec flex-wrap: wrap
• 8 cartes avec fond coloré et un titre

7. Les propriétés des enfants (flex-grow, shrink, basis)

7.1 Le trio fondamental

Chaque enfant flex peut être configuré individuellement avec trois propriétés : flex-grow, flex-shrink et flex-basis.

PropriétéRôleValeur par défaut
flex-growCapacité à grandir pour occuper l'espace libre0
flex-shrinkCapacité à rétrécir si l'espace manque1
flex-basisTaille de base avant répartitionauto

7.2 flex-grow

Définit la proportion d'espace libre que l'élément peut absorber. Un ratio plus élevé signifie plus d'espace.

🧪 Démonstration interactive · flex-grow
flex-grow: 1 / 1 / 1
1
2
3
flex-grow: 1 / 2 / 1
1
2
3
flex-grow: 3 / 1 / 1
1
2
3
flex-grow: 1 / 0 / 0
1
2
3
📌 Calcul : si 3 éléments ont flex-grow: 1, 2 et 1, l'espace libre est réparti en 4 parts (1+2+1). Le 2ᵉ élément reçoit 2/4, les autres 1/4 chacun.

7.3 flex-shrink

Définit la capacité de rétrécissement quand l'espace manque. Une valeur de 0 empêche l'élément de rétrécir.

/* Un élément qui ne doit jamais rétrécir */ .sidebar { flex-shrink: 0; /* Taille fixe, refuse de rétrécir */ width: 250px; } /* Un élément qui peut rétrécir normalement */ .contenu { flex-shrink: 1; /* Par défaut */ }

7.4 flex-basis

Définit la taille initiale de l'élément avant répartition d'espace. Peut être en px, %, auto, etc.

/* Taille de base de 200px */ .carte { flex-basis: 200px; } /* Taille basée sur le contenu */ .auto { flex-basis: auto; } /* Taille proportionnelle au conteneur */ .pct { flex-basis: 30%; }

7.5 La propriété raccourcie flex

Combine les trois propriétés en une seule ligne : flex: <grow> <shrink> <basis>.

SyntaxeSignification
flex: 1flex: 1 1 0 — prend une part égale
flex: autoflex: 1 1 auto — taille selon contenu puis répartition
flex: noneflex: 0 0 auto — taille fixe selon contenu
flex: 2flex: 2 1 0 — prend 2 parts sur l'espace libre
flex: 1 0 200pxGrow 1, ne rétrécit pas, base 200px

7.6 Le layout "sidebar + contenu"

Un cas d'usage classique : barre latérale fixe + contenu principal flexible.

🧪 Démonstration · Sidebar fixe + contenu flexible
Sidebar (200px fixe)
Contenu principal (flexible)
/* Layout classique */ .layout { display: flex; gap: 20px; } .sidebar { flex: 0 0 250px; /* Largeur fixe */ } .contenu { flex: 1; /* Prend tout l'espace restant */ }
Contexte : Un conteneur de 900px contient 3 blocs avec flex-grow: 1 / 2 / 3 et flex-basis: 100px chacun.

1. Quelle est la taille de base totale des 3 blocs ?
2. Quel espace reste-t-il à distribuer ?
3. Combien de parts au total ?
4. Quelle est la taille finale de chaque bloc ?
5. Si on change en 1 / 1 / 1, quelle serait la taille de chaque bloc ?
6. Quel est l'effet de flex-shrink: 0 ?
⏳ 90 s
💡 Solution :
1. Taille de base totale : 3 × 100 = 300px
2. Espace libre à distribuer : 900 − 300 = 600px
3. Parts totales : 1 + 2 + 3 = 6 parts
4. Chaque part = 600 / 6 = 100px. Donc :
  • Bloc 1 : 100 + 100×1 = 200px
  • Bloc 2 : 100 + 100×2 = 300px
  • Bloc 3 : 100 + 100×3 = 400px
5. Avec 1/1/1 : 200px pour chacun (300 base + 600 libre / 3)
6. flex-shrink: 0 empêche l'élément de rétrécir ; il garde sa taille même si l'espace manque
Consigne : Créez un layout de dashboard avec :

• Une zone de contenu principal qui prend le reste de l'espace
• Un widget latéral droit fixe de 300px
• La zone de contenu contient 3 cartes en grille interne

• Sidebar : flex: 0 0 250px
• Contenu : flex: 1
• Widget : flex: 0 0 300px

Permet de réorganiser visuellement les enfants flex sans changer l'ordre du HTML. C'est très utile pour le responsive (inverser sur mobile).

1

3

1
2
3
Avec order: -1 sur le 3ᵉ
1
2
3
/* Réorganisation visuelle */ .element-1 { order: 3; } .element-2 { order: 1; } .element-3 { order: 2; } /* Résultat visuel : 2, 3, 1 */
📌 Valeur par défaut : order: 0.
• Les valeurs négatives placent l'élément avant
• Les valeurs positives le placent après
• À valeurs égales, l'ordre HTML est conservé.

8.3 Cas d'usage pour le responsive

Un usage classique : sur desktop, le contenu est à droite de l'image ; sur mobile, on veut mettre l'image en premier.

/* Desktop : image à gauche, texte à droite */ .section { display: flex; gap: 20px; } .section .image { order: 1; } .section .texte { order: 2; } /* Mobile : image en premier (par défaut, pas de changement) */ @media (max-width: 768px) { .section { flex-direction: column; } .section .image { order: 1; } .section .texte { order: 2; } }
Contexte : HTML dans cet ordre : A, B, C, D, E.

1. Avec order: 0 / 0 / 0 / 0 / 0, quel est l'ordre visuel ?
2. Avec order: 1 / 2 / 3 / 4 / 5, quel est l'ordre visuel ?
3. Avec order: 3 / 1 / 2 / 5 / 4, quel est l'ordre visuel ?
4. Avec order: 0 / -1 / 0 / 0 / 0, quel est l'ordre visuel ?
5. Avec order: 0 / 0 / 0 / 0 / -1, quel est l'ordre visuel ?
6. Quelle est la différence entre changer order et changer l'ordre HTML ?
⏳ 90 s
💡 Solution :
1. Ordre HTML conservé : A, B, C, D, E
2. Ordre croissant : A, B, C, D, E (déjà croissant)
3. Trié par order croissant : B(1), C(2), A(3), E(4), D(5) → B, C, A, E, D
4. B a order -1 : B, A, C, D, E
5. E a order -1 : E, A, B, C, D
6. order ne change que l'ordre visuel (lecture d'écran et SEO conservent l'ordre HTML). Changer l'HTML modifie aussi la sémantique.

Énoncé : Créez une carte de profil avec 3 éléments dans cet ordre HTML :
