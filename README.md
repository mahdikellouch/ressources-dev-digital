## 🎯 Comment utiliser ce dépôt ?

### 1. Consulter les ressources en ligne
Le plus simple : ouvrez le **site web** (voir lien ci-dessus).

### 2. Consulter les ressources sur GitHub
Cliquez sur le dossier du module qui vous intéresse. Chaque module contient :
- 📂 **`supports/`** : cours, présentations, fiches de révision
- 📂 **`activites/`** : activités collaboratives
- 📂 **`exercices/`** : énoncés d'exercices à réaliser
- 📂 **`projets/`** : mini-projets et projets de synthèse
- 📂 **`corrections/`** : solutions (à consulter après avoir essayé)
- 📂 **`evaluations/`** : sujets de CC, EFM et corrigés

### 3. Cloner le dépôt (pour les plus avancés)

```bash
git clone https://github.com/ismO-ofppt/ressources-dev-digital.git
```

## 📋 Règles de collaboration

### Pour poser une question
- Ouvrez une **Issue** (onglet "Issues" en haut)
- Exemple de titre : `[M105] Question sur les boucles for`
- Je répondrai dans le fil de discussion

### Pour proposer une correction
- Ouvrez une **Pull Request** avec votre proposition
- Expliquez brièvement vos changements

### Pour signaler une erreur
- Ouvrez une **Issue** en précisant le module et le fichier concerné
