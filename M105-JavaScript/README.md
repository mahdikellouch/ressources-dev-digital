# M105 · Programmer en JavaScript

Bienvenue dans le module **M105 — Programmer en JavaScript : du langage au DOM**.
Ce module fait partie de la filière Développement Digital (1ère année (tronc commun)).

---

## 🎯 Objectifs du module

À l'issue de ce module, vous serez capable de :
- Comprendre les fondamentaux du langage JavaScript
- Manipuler des variables, des types et des opérateurs
- Écrire des structures conditionnelles et des boucles
- Créer et utiliser des fonctions
- Manipuler le DOM (Document Object Model)
- Gérer les événements utilisateur
- Interagir avec des API simples (fetch)

**Durée** : 110 h
**Niveau** : Débutant → Intermédiaire
**Prérequis** : M104 — Développer des sites web statiques

## 🚀 Comment travailler ?

### Étape 1 — Lire le support
Chaque séance commence par la lecture du support correspondant dans `supports/`.

### Étape 2 — Faire les exercices
Rendez-vous dans `exercices/` et réalisez les exercices dans l'ordre. Ne regardez **pas** les corrections avant d'avoir essayé.

### Étape 3 — Comparer avec la correction
Une fois l'exercice terminé, ouvrez le dossier `corrections/` pour comparer votre solution.

### Étape 4 — Réaliser les projets
Les projets sont l'occasion de mettre en pratique tout ce que vous avez appris.

## 💡 Conseils pour réussir

1. **Pratiquez tous les jours** : 30 minutes par jour valent mieux que 3 heures une fois par semaine.
2. **Ne copiez pas les corrections** : essayez d'abord, puis comparez.
3. **Posez des questions** : utilisez les Issues GitHub ou le canal Teams.
4. **Documentez votre code** : ajoutez des commentaires pour expliquer votre logique.
5. **Travaillez en groupe** : discuter d'un problème aide à mieux comprendre.
